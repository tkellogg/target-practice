# Style Guide

## General Design Principles
- Everything works for both light and dark modes
- Moderate visual contrast between separate items
- Hovering over items with actions should be visually different from it's background and surrounding text
- Hover should NEVER cause visual movement (e.g. no expanding or contracting, no padding changes, etc.)
- Prefer slightly rounded corners, radius 2px

## Resume Editor View
- Each experience item should be visually separate. Utilize space and/or colors
to easily distinguish these list items.
